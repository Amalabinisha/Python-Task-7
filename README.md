# Image Resizer Tool

Batch resize and convert images in a folder using Python and Pillow.

## Usage

1. Install Pillow:
    ```
    pip install Pillow
    ```
2. Place images in `input_folder`.
3. Run:
    ```
    python resize_images.py
    ```
4. Resized images will be saved in `output_folder` as PNG.

## Config

- Change size in script: `target_size = (width, height)`
- Edit folder names if needed.

## Requirements

- Python 3.x
- Pillow
